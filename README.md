# BÀI TẬP TỔNG HỢP: HÀNH TRÌNH XỬ LÝ 1 LỖI CÀI ĐẶT THẬT

## PHẦN 1 – TÌM KIẾM GOOGLE

### 1. Câu hỏi ban đầu tìm kiếm kém hiệu quả vì viết dài dòng, mang tính giao tiếp và thiếu từ khóa chính.

### 2. Bóc tách lỗi:
- Phần mềm / Hệ điều hành: Node.js / Windows 11.
- Mã lỗi: 'npm' is not recognized as an internal or external command, operable program or batch file.
- Thao tác: Nhập lệnh npm -v trong Terminal của VS Code.
### 3. Ba câu tìm kiếm:
- site:stackoverflow.com npm not recognized Windows 11
- "npm is not recognized as an internal or external command"
- npm not recognized Windows -windows-xp
## PHẦN 2 – KIỂM TRA STACKOVERFLOW

### 1. So sánh:

Chọn câu A vì đáng tin cậy và phù hợp với Windows 11. Câu B không phù hợp vì hướng dẫn dành cho Windows XP.

### 3. Các bước kiểm tra:
- Xem tiêu đề bài viết.
- Kiểm tra Tags.
- Kiểm tra tích xanh.
- Xem lượt bình chọn.
- Kiểm tra thời gian đăng.
## PHẦN 3 – HỎI AI

### 1. Prompt:

Tôi đang sử dụng Windows 11 và vừa cài Node.js. Tôi đã thêm đường dẫn Node.js vào PATH nhưng khi nhập npm -v vẫn gặp lỗi:

'npm' is not recognized as an internal or external command, operable program or batch file.

Hãy giải thích nguyên nhân và hướng dẫn tôi cách sửa lỗi bằng tiếng Việt, đơn giản và an toàn.

### 2. Đánh giá câu trả lời AI:

Không an toàn vì lệnh được đề xuất có thể xóa toàn bộ tệp quan trọng trong System32, khiến Windows bị lỗi.

### 3. Phản hồi AI:

Hãy giải thích vì sao cần xóa thư mục System32 để sửa lỗi PATH. Có cách nào khác an toàn hơn mà không ảnh hưởng đến hệ thống không?

## PHẦN 4 – VIẾT BUG REPORT

### 1. Tin nhắn kém:

Thầy ơi, máy em bị lỗi npm, thầy giúp em với ạ.

### 2. Tin nhắn chuẩn:

Context: Em sử dụng Windows 11, vừa cài Node.js và mở Terminal trong VS Code.

Expected: Khi nhập npm -v, máy sẽ hiển thị phiên bản npm.

Actual: Máy báo lỗi npm is not recognized. Em đã thêm PATH và mở lại Terminal nhưng vẫn không sửa được.

Log & Screenshot: Em gửi ảnh chụp màn hình thông báo lỗi để thầy kiểm tra.

### 3. Phím tắt và lưu ý:
- Phím tắt: Windows + Shift + S.
- Lưu ý: Che mật khẩu và thông tin cá nhân trước khi gửi ảnh.
